# 와이즈토토 배당 이력 데이터 품질 검증 결과 (2026-08-07)

## 목적

전체 범위 검사에서 발견된 비정상 후보 15건과 2010~2012년의 다중 변경 이력 부재를 확인하고,
단일 연도의 실제 배당 시퀀스를 파일로 추출할 수 있는지 검증했다.

## 비정상 후보 15건 분석

전체 70,157경기 중 파서가 신뢰 가능한 시퀀스로 만들지 못한 후보는 15건(약 0.021%)이다.

| 원인 | 경기 수 | 처리 방침 |
|---|---:|---|
| 승·무·패 항목별 변경 횟수 불일치 | 5 | 순서를 추정하지 않고 제외 |
| 변경 이력 마지막 값과 화면 최종 배당 불일치 | 10 | 값을 보정하지 않고 제외 |

항목별 변경 횟수가 다른 경우 어느 변경 시점에 나머지 배당이 유지됐는지 원문만으로 확정할 수 없다.
최종 값이 다른 경우에도 중간 변경 누락인지 별도 최종 변경인지 구분할 수 없다. 임의 보간이나 최종 값
덮어쓰기는 학습 데이터에 잘못된 흐름을 만들 수 있으므로 적용하지 않는다.

재현 원문과 경기 식별자, 파싱 실패 사유는
`artifacts/odds-history-quality/malformed_candidates.json`에 저장했다.

## 2010~2012년 다중 변경 이력 부재

전체 검사 체크포인트의 경기별 스냅샷 수를 다시 집계한 결과는 다음과 같다.

| 연도 | 최종 배당만 존재 | 2개 스냅샷 | 3개 이상 스냅샷 |
|---:|---:|---:|---:|
| 2010 | 1,537 | 375 | 0 |
| 2011 | 2,285 | 404 | 0 |
| 2012 | 1,991 | 1,924 | 0 |
| 2013 | 2,984 | 826 | 142 |

2010~2012년에는 변경 이력이 있는 모든 경기에서 정확히 한 번의 변경만 노출된다. 2013년부터는
최대 7개 스냅샷을 가진 경기가 확인된다. 이는 파서의 연도별 분기 문제가 아니라 공개 원문이 제공하는
이력 깊이의 차이로 판단된다. 다만 사이트가 실제 모든 변경을 보존한다는 계약이나 명세가 없으므로,
2010~2012년의 한 번 변경이 실제 전체 변경 이력이라고 보장할 수는 없다.

## 결론 및 본개발 전환 판단

공개 데이터만으로 연도 단위 자동 수집, 경기 결과 결합, 순서가 있는 승·무·패 배당 시퀀스 저장이
가능함을 확인했다. 비정상 데이터는 전체 대비 매우 적고 명시적으로 제외할 수 있으므로 수집 파이프라인
본개발을 시작할 수 있다.

단, 다음 제약은 데이터 계약에 반영해야 한다.

- 정확한 변경 시각 부재
- 공개 사이트가 모든 변경을 보존한다는 보장 부재
- 2010~2012년은 최대 2개 스냅샷만 확인됨
- 원문 불일치 데이터의 추정 복구 금지
- HTML/AJAX 변경 감시와 실패 원문 보관 필요

다음 작업은 2010~2026년 원본 시퀀스 수집 파이프라인의 체크포인트·재시도·품질 격리 구현이며,
그 이후 pandas 기반 중복·결측·분포 분석과 학습 데이터셋 구축으로 진행한다.
