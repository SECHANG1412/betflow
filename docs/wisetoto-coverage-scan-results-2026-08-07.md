이력을 어느 범위까지 자동 수집할 수 있는지 검증한다.

- 요청 간격: 회차당 1초
- 실패 대응: 최대 2회 재시도, 회차별 체크포인트 저장
- 2026년 데이터: 검사일인 2026-08-07까지 공개된 회차만 포함

## 데이터 가용성 판단

### 확인된 사항

- 2010년부터 2026년까지 공개 회차 자동 탐색 가능
- 로그인과 유료 API 없이 전체 1,894회차 연속 조회 가능
- 경기 결과와 배당 변경 순서 동시 확보 가능
- 중단 후 체크포인트 기반 재개 가능
- 약 45분간의 전체 검사에서 원격 요청 실패 0건

### 제한 사항

- 배당 변경의 정확한 시각 미제공
- 전체 경기 중 65.57%는 변경 전 배당 없이 최종 배당만 확인
- 사이트가 공개한 변경 이력이 실제 발생한 모든 변경을 포함하는지 검증 불가
- 2010~2012년의 다중 변경 이력 부재로 연도별 보존 수준 차이 가능성 존재
- HTML과 비공개 문서화 AJAX 구조 의존으로 사이트 개편 시 파서 수정 필요
- 형식 이상 후보 15건에 대한 원본 응답 수동 확인 필요

## 안정성 평가

현재 구조는 일회성 연구용 수집에는 사용할 수 있다. 체크포인트, 요청 간격, 재시도 처리가 있어
장시간 실행을 복구할 수 있고 실제 전체 검사도 완료했다. 다만 공식 API 계약이 없으므로 장기
운영 안정성은 낮음~보통으로 평가한다. 응답 구조 감시, 파서 회귀 테스트, 실패 회차 재처리가
필요하다.

실행 중 Windows에서 체크포인트 임시 파일 교체가 잠기는 문제가 재현됐다. 파일 교체를 짧게
재시도하도록 수정한 뒤 전체 검사를 완료했다.

## 결론

2010~2026년의 과거 배당 변경 순서와 경기 결과를 무료 공개 데이터만으로 자동 수집할 수 있다는
핵심 가능성은 확인됐다. 흐름 기반 모델 후보 데이터는 최소 24,153경기이며, 그중 세 시점 이상인
경기는 4,933경기다.

다만 이번 검사는 범위와 보존율을 확인한 것이며 실제 70,157경기의 전체 배당값을 저장한 작업은
아니다. 따라서 모델·프론트엔드·DB 본설계는 아직 시작하지 않는다. 다음 단계에서 정상 경기의
원본 배당 시퀀스를 대량 추출하고, 15개 형식 이상 후보와 연도별 포맷 차이를 검증한 뒤 최종
학습 가능 데이터 수를 확정한다.
